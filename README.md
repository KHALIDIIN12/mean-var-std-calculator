# Mean-Variance-Standard Deviation Calculator

A Python project that calculates statistical measures from a 3x3 matrix using NumPy.

## Description

This project is part of the freeCodeCamp Data Analysis with Python certification. The function `calculate()` takes a list of 9 numbers, converts it into a 3x3 NumPy array, and returns a dictionary containing the mean, variance, standard deviation, max, min, and sum along both axes and for the flattened matrix.

## Features

- Validates input to ensure exactly 9 numbers are provided
- Calculates mean, variance, standard deviation, max, min, and sum
- Returns results for columns (axis 0), rows (axis 1), and the flattened matrix
- Handles errors with a clear ValueError message

## Technologies Used

- Python 3
- NumPy
